# Grillabend JJJJ-MM-TT

Kopieren nach `docs/cooks/JJJJ-MM-TT/README.md` und ausfüllen. Was nicht bekannt ist, leer
lassen. Diese Angaben erklären später Unterschiede zwischen den Modellen (`tools/fit_plant.py`):
Kälte und Wind ziehen Wärme ab, Grillgut und Wasser schlucken Wärme, beides verschiebt tMin/tMax
und die Zeitkonstante.

## Bedingungen

| | |
|---|---|
| Ort | Garage (Tor offen/zu) / draußen / überdacht |
| Außentemperatur | °C (am besten ein freier Fühler außen im Schatten, siehe unten) |
| Wind | kein / leicht / böig / stark, Richtung zum Smoker (von vorn, hinten, seitlich) |
| Regen / Sonne | |
| Wasserschale | voll um HH:MM, nachgefüllt um …, leer ungefähr um … |
| Grillgut | was, wie viel (kg), Starttemperatur (Kühlschrank / Raum), aufgelegt um … |
| Deckel offen | Uhrzeiten (zum Prüfen der Deckel-Erkennung) |
| Gasflasche | voll / halb / fast leer (bei Kälte sinkt der Druck) |

## Aufbau

| | |
|---|---|
| Firmware | v1.2.4-gas.N |
| Profil | Nr., SPmin, SPmax, Kp/Ki/Kd, Smart an/aus |
| Fühler | Kanal → Position (Regelkanal Mitte, unten über Wasser, oben, außen) |
| Mitschrieb | Datei, Intervall (5 s) |
